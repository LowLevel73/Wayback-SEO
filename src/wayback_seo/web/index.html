    Wayback SEO

    Wayback SEO uses the Wayback Machine to find problems in a website's past.

    The down detector shows the weeks in which URLs stopped working (from 200 to an error) and started working again. When a site is completely unreachable, the archive saves nothing, so a week with far fewer captures than usual can also mean an outage.

    Advanced options

    The migration check collects the URLs that worked before the migration and checks each one on the live site today. After a good migration, every old URL still works or redirects permanently to a working page. This tool sends requests to the site, so use it only on sites you are allowed to audit.

    Advanced options

    The robots.txt history shows every version of robots.txt that the archive saved, and which rules each version added or removed. The tool groups the rules the same way Googlebot does, and it highlights serious changes.
